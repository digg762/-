Lootly на Render: пошагово

1. GitHub
   Создайте репозиторий (кнопка New). Нажмите Add file -> Upload files и перетащите
   ВСЁ содержимое этой папки, включая папку public. Нажмите Commit changes.
   Ключ RAWG в файлах нигде не указан, так и должно быть.

2. Render
   New -> Web Service -> выберите свой репозиторий.
   Runtime: Node
   Build Command: оставьте пустым (или npm install)
   Start Command: npm start
   Instance Type: Free

3. Ключ
   В настройках сервиса откройте Environment -> Add Environment Variable:
   Key:   RAWG_KEY
   Value: ваш ключ RAWG
   Сохраните. Сервис перезапустится сам.

4. Откройте адрес вида lootly.onrender.com. Обложки подтягиваются по мере прокрутки.
   На бесплатном тарифе сервис засыпает без посетителей, первая загрузка после паузы
   занимает около минуты.

Проверка: если вместо обложек цветные плитки, откройте в браузере
адрес-вашего-сайта/api/cover?id=1
  503: переменная RAWG_KEY не задана
  502: RAWG отклонил ключ или запрос (проверьте ключ)
  переход на картинку: всё работает
