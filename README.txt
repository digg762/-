Lootly на Render: пошагово

0. ПАРОЛЬ НА ВХОД
   Сайт теперь закрыт паролем: без ввода пароля открывается страница входа,
   все страницы и /api/* отдаются только после входа.
   Пароль меняется в одном месте — в файле server.js, переменная SITE_PASSWORD
   (в самом верху файла, в кавычках). Или можно задать переменную окружения
   SITE_PASSWORD на Render (Environment -> Add Environment Variable) —
   тогда значение из кода игнорируется.
   Выйти с сайта: Настройки -> «Выйти везде».

1. GitHub
   Откройте свой репозиторий -> Add file -> Upload files и перетащите ВСЁ содержимое
   этой папки (включая public) поверх старых файлов. Commit changes.
   Render сам перезапустит сайт после коммита.
   Ключи в файлах нигде не указаны, так и должно быть.

2. Render -> ваш сервис -> Environment. Должно быть ДВЕ переменные:

   RAWG_KEY               ключ RAWG (обложки игр)
   BRANDFETCH_CLIENT_ID   Client ID с brandfetch.com, раздел Developer Portal
                          (логотипы приложений)

   Названия пишите точно так, большими буквами, без кавычек и пробелов.

3. Проверка (подставьте адрес своего сайта):
   /api/cover?id=1     должно перекинуть на картинку (игра Roblox)
   /api/icon?id=445    должно перекинуть на логотип (приложение ChatGPT)
   Коды ошибок:
   503  переменная не задана
   502  RAWG отклонил запрос (проверьте ключ, смотрите Logs в Render)
   404  для этой игры или приложения картинки нет, останется цветная плитка

Если у приложения не нашёлся логотип, показывается цветная плитка с буквами.
Часть адресов сайтов в apps.txt я подобрал по памяти (например NoPing, Crosshair X):
если логотип не тот или не появился, поправьте домен в третьей колонке apps.txt.
