Lutrix Game на Render: пошагово

1. GitHub
   Откройте репозиторий -> Add file -> Upload files, перетащите ВСЁ содержимое этой
   папки (вместе с папкой public) поверх старых файлов -> Commit changes.
   Ключи и пароли в файлах не хранятся, так и должно быть.

2. Render -> ваш сервис -> Settings -> Build Command: впишите
       npm install
   (без этого не установится драйвер базы и аккаунты не сохранятся). Save Changes.

3. Render -> Environment. Переменные (имена точно такие, без кавычек и пробелов):

   DATABASE_URL           ссылка на базу из Neon (Connection string). Уже добавлена
   OWNER_CODE             ваш секретный промокод владельца (придумайте сами, длинный)
   SITE_PASSWORD          пароль на вход в сайт (уже есть)
   RAWG_KEY               ключ RAWG (обложки игр)
   BRANDFETCH_CLIENT_ID   Client ID с brandfetch.com (логотипы приложений)
   RESEND_API_KEY         ключ resend.com (письма с кодом), по желанию
   MAIL_FROM              отправитель писем, например: Lutrix Game <noreply@ваш-домен.ru>
   TOPUP_FEE              комиссия с пополнения в рублях, по умолчанию 1

4. Проверка, что база подключилась
   Render -> Logs после запуска. Должна быть строка:
       Хранилище готово: postgres, пользователей: ...
   и в первой строке "(хранилище: Postgres (DATABASE_URL))".
   Если написано "файл" или "ФАЙЛ", значит драйвер не установился (проверьте
   Build Command) или DATABASE_URL не задан: тогда данные пропадают при перезапуске.

5. Как стать владельцем
   Войдите в аккаунт -> Настройки -> Промокод -> введите значение OWNER_CODE.
   С этого момента комиссии с пополнений всех пользователей идут на баланс этого
   аккаунта. Данные площадки (пользователи, объявления, заказы, доходы) видны в
   профиле, вкладка «Баланс».
   Если владельцев несколько, доходы идут тому, кто ввёл код первым.

6. Как проверить продажу и покупку (нужны три аккаунта)
   - Продавец: кнопка «Создать объявление» на главной (или «Продать» в шапке).
   - Покупатель: значок баланса в шапке -> пополнить (минимум 10 ₽, комиссия 1 ₽
     уходит владельцу, остальное на баланс) -> открыть игру -> Купить.
   - Автовыдача: покупатель сразу видит данные. Ручная выдача: продавец пишет данные
     в профиле, вкладка «Продажи».
   - Деньги продавцу приходят, когда покупатель нажмёт «Подтвердить получение»
     (или сами через 72 часа после выдачи). До выдачи заказ можно отменить: деньги
     вернутся покупателю.
   Все деньги виртуальные, настоящих платежей нет.

7. Забыли пароль
   В окне входа есть ссылка «Забыли пароль?»: на почту приходит код, по нему задаётся
   новый пароль. Пока RESEND_API_KEY не задан, код смотрите в Render -> Logs, строка
   [ПОЧТА НЕ ПОДКЛЮЧЕНА] Код восстановления пароля для ...: 123456
   Важно: Resend разрешает письма на любые адреса только после подтверждения
   собственного домена. С адреса onboarding@resend.dev письма идут только на почту,
   на которую зарегистрирован ваш аккаунт Resend.

8. Что сейчас хранится в базе, а что нет
   В базе: аккаунты, входы, баланс и история операций, объявления, заказы, аватары.
   Только в браузере: избранное, корзина магазина игр, тема, валюта, «О себе» и страна.

9. Проверка обложек и иконок (подставьте адрес своего сайта)
   /api/cover?id=1     перекинет на картинку (игра Roblox)
   /api/icon?id=445    перекинет на логотип (приложение ChatGPT)

10. Логотип лежит в public/logo.png. Чтобы заменить, подмените этот файл.
