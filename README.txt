Lootly на Render: пошагово

1. GitHub
   Откройте свой репозиторий -> Add file -> Upload files и перетащите ВСЁ содержимое
   этой папки (включая папку public) поверх старых файлов. Commit changes.
   Render сам перезапустит сайт после коммита.
   Ключи и пароли в файлах не хранятся, так и должно быть.

2. Render -> ваш сервис -> Environment. Переменные:

   SITE_PASSWORD          пароль на вход в сайт (уже есть, оставьте только здесь,
                          в файлы его не вписывайте)
   RAWG_KEY               ключ RAWG (обложки игр)
   BRANDFETCH_CLIENT_ID   Client ID с brandfetch.com (логотипы приложений)

   Для настоящих писем с кодом (можно добавить позже, см. пункт 4):
   RESEND_API_KEY         ключ с resend.com
   MAIL_FROM              отправитель, например: Lootly <noreply@ваш-домен.ru>

   Названия пишите точно так, большими буквами, без кавычек и пробелов.

3. Порядок входа на сайт
   Пароль на сайт -> сайт открывается, поверх него панель регистрации
   (один раз за сеанс, её можно закрыть) -> вход или регистрация -> код из письма.
   Покупка и профиль доступны только после входа в аккаунт.

4. Код подтверждения
   Пока RESEND_API_KEY не задан, письма НЕ отправляются. Код печатается в журнал:
   Render -> ваш сервис -> Logs, строка
   [ПОЧТА НЕ ПОДКЛЮЧЕНА] Код подтверждения для ...: 123456
   Когда добавите RESEND_API_KEY, коды будут приходить на почту, а в журнал попадать
   перестанут.
   Важно: Resend разрешает письма на любые адреса только после подтверждения
   собственного домена. С адреса onboarding@resend.dev письма идут только на почту,
   на которую зарегистрирован ваш аккаунт Resend.

5. Где хранятся аккаунты (временно)
   Аккаунты лежат в файле на сервере. На бесплатном Render он стирается при каждом
   обновлении сайта, перезапуске и после 15 минут без посетителей. Для настоящего
   запуска нужна база данных. Пока это проверка панели и всего пути регистрации.

6. Проверка (подставьте адрес своего сайта)
   /api/cover?id=1     перекинет на картинку (игра Roblox)
   /api/icon?id=445    перекинет на логотип (приложение ChatGPT)
   Коды: 503 переменная не задана, 502 сервис отклонил запрос, 404 картинки нет.

7. Логотип лежит в public/logo.png. Чтобы заменить, подмените этот файл.
